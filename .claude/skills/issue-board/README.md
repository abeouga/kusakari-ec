# issue-board

GitHub の issue にある「決めること」を、claude.ai の Whiteboard(Artifact)に書き出す Claude Code のスキルです。
チームで相談するときに、未決の項目と決定済みの項目をボード上で見比べたり、各項目の横にメンバーが考えを書き込んだりできるようにします。

## できること

- issue 本文の「決めること」セクションを、項目ごとのカードにしてボードに並べる
- コメントのうち、どれかの項目について意見・決定・取り下げを書いたものを、その項目のカードに足す
- 未決の項目は緑、決定済み(「決定：」の行がある)の項目は白のカードにする
- 各項目の右に、メンバーが書き込むための空のカードを置く
- 同じ issue でもう一度呼ぶと、新しい区画は作らず、変わった項目だけを書き換え、増えた項目を足す

GitHub の issue は読むだけで、コメントやチェック欄の変更などの書き込みはしません。

## 使い方

Claude Code で次のように呼びます。

```
/issue-board <WhiteboardのURL> <issueのURL>
```

実際の URL を入れると、次のようになります。

```
/issue-board https://claude.ai/artifact/xxxxxxxx https://github.com/owner/repo/issues/194
```

2つの URL の順番は逆でもかまいません。

### ボードの URL を保存する

一度ボードの URL を付けて呼ぶと、その URL が `config.json` に保存されます。
2回目からは issue の URL だけで呼べます。

```
/issue-board https://github.com/owner/repo/issues/195
```

別のボードに書きたいときは、そのボードの URL を付けて呼びます。このとき、保存されている URL は新しいものに置き換わります。

## 設定ファイル(config.json)

`config.json` はスキルのフォルダ(通常は `~/.claude/skills/issue-board/`)にあり、次の形で書きます。

```json
{
  "whiteboard_url": "https://claude.ai/artifact/..."
}
```

| キー | 内容 |
|---|---|
| `whiteboard_url` | issue を書き出すボードの URL。`https://claude.ai/artifact/...` の形。空のときは、ボードの URL を付けて呼ぶ必要がある |

`config.json` は手で書き換えてもかまいません。

## 必要なもの

- Claude Code(Artifact ツールと ArtifactData ツールが使えること)
- 書き込み先の Whiteboard を編集できる claude.ai のアカウント
- `gh`(GitHub CLI)。対象の issue を読める状態でログインしておく

## ボードの見た目

issue 1つにつき、1つの区画を作ります。

```
┌ #194 譲渡先が承認するまでの流れ ───────────────────────────┐
│ [issue #194 を開く](リンク) ｜ 緑＝未決 白＝決定済み          │
│                                                              │
│ [決めることの内容1] ──→ [メンバーが書き込むカード]           │
│ [決めることの内容2] ──→ [メンバーが書き込むカード]           │
│  …                                                           │
└──────────────────────────────────────────────────────────────┘
```

- 左のカードには問い・補足・ボードでの案・各人の意見・決定を書きます
- 右のカードは枠だけの空のカードです。2回目以降の呼び出しでも中身は変えません
- 人がボードに書き足した付箋や線などは、動かしたり消したりしません

## 注意

- issue に「決めること」の見出しが無いときは、ボードに何も書きません
- issue から消えた項目のカードは消さずに残し、報告で知らせます
- 1回の呼び出しで書くのは、指定した1つの issue だけです

## ファイル

| ファイル | 内容 |
|---|---|
| `SKILL.md` | スキルの手順(Claude が読む) |
| `config.json` | 保存したボードの URL |
| `README.md` | このファイル |
