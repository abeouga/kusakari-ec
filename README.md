# 主な機能
1. **ショッピングサイト機能**<br>
一般的なショッピングサイトのように商品を検索し、カートに入れた商品を購入できます。<br>
2. **3D機能**<br>
実際の庭を写真を利用し、その写真上に 植物の3Dモデルを配置して植物の配置イメージを確認できます。<br>
3. **イメージ作成機能**<br>
3D機能で作成した庭の状態から AIで実写の配置後イメージを作成します。<br>
4. **3D機能で配置した植物を購入**<br>
3D機能で配置した植物の 3Dモデルは、実際に販売されている商品と紐づいているので、そのままカートに入れることで決済ができます。
